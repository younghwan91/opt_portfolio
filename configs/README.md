# configs/ — 공개 예제와 비공개 운용 설정

이 디렉터리의 설정은 **방법을 보여주는 예제**다. 엔진이 무엇을 받고 어떻게
선언하는지를 읽을 수 있게 두는 것이 목적이다.

## 왜 나누는가

채택 전략의 유니버스는 시총 $5M~$80M 초소형주다. 이 규모에서는 **용량이
극도로 작다** — 같은 종목을 사는 사람이 몇십 명만 늘어도 체결가가 밀린다.

보유 종목을 공개하지 않는 것만으로는 부족하다. **시총 밴드와 팩터 조합이
종목을 결정하기 때문**에, 레시피가 있으면 같은 종목이 나온다. 종목만 감추는
것은 반쪽짜리다.

## 규칙

| | 어디에 두는가 |
|---|---|
| 예제·연구용 설정 | `configs/*.json` (공개) |
| 실제 운용 파라미터 | **저장소 밖** — 예: `~/data/strategy_live.json` |

`--config` 는 임의 경로를 받으므로 코드 변경이 필요 없다.

```bash
opt-factor optimize --store ~/data/us_micro.duckdb \
  --config ~/data/strategy_live.json --space configs/space_small.json
```

저장소 안에서 굴려야 한다면 `*.private.json` 또는 `configs/private/` 를 쓴다.
`.gitignore` 가 막고, pre-commit 훅이 `git add -f` 까지 막는다.

## 되돌릴 수 없다는 점

이 장치들은 **앞으로** 를 막을 뿐이다. 한 번 푸시된 설정은 히스토리·포크·
GitHub 캐시에 남아 사후에 감출 수 없다. 유출된 열쇠와 같아서, 비공개로
가려면 **파라미터를 새로 도출하는 수밖에 없다.**
