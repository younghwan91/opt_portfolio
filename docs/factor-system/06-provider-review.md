# 데이터 프로바이더 전수 조사 (2026-08)

구독 가능한 미장 데이터 서비스 전체를 우리 시스템의 5가지 요구사항으로 채점한 기록.
결론이 바뀌면 이 문서를 갱신한다.

## 평가 기준 (시스템 설계에서 도출 — 협상 불가 순서)

| # | 기준 | 왜 협상 불가인가 |
|---|---|---|
| ① | **PIT (공시일 + 원본값 보존)** | 스토어가 datekey 를 요구. 재작성값으로 덮어쓰는 소스는 look-ahead 를 주입 |
| ② | **상장폐지 포함** | 없으면 생존 편향으로 CAGR ~5%p 과대평가 (Norgate 실측 사례) |
| ③ | **팩터 커버리지** | 재무 전항목 + R&D + 무형자산 + 13F + 내부자 + (공매도·추정치) |
| ④ | **히스토리 2003~** | 요청된 백테스트 시작일. 닷컴 붕괴 직후 포함이 검증력의 핵심 |
| ⑤ | **개인 예산** | 월 수십 달러. 기관 계약($10k+/yr) 배제 |

## 판정 상세

### 왜 Sharadar 인가 — 대체 불가 조합

①+②를 **동시에** 만족하는 개인 가격대 서비스는 Sharadar 가 유일하다.
- Tradevo 는 ① 은 더 우아하지만 (서버측 as_of) 연간 재무 12년·폐지 미포함·가격 없음 — 우리 백테스트가 성립 안 함.
- EODHD 는 커버리지·가격이 좋지만 재작성값 덮어쓰기 — **우리 스토어의 "최초 공시 우선" 불변식과 정면 충돌.** 이 하나로 탈락이다.
- 게다가 SF2(내부자)/SF3(13F)가 같은 티커 체계에 붙어 있어 수급 프록시 팩터가 추가 비용 없이 나온다.

가격 검증: 직판 4티어 = Fundamentals $19 / Prices $9 / Investors $9 / **Bundle $29**.
(과거 Nasdaq Data Link 경유 $150/mo 대비 1/5 수준.)

### 왜 FMP 는 보조 전용인가

FMP 재무제표는 `acceptedDate` (SEC 접수시각) 를 제공하지만 **값 자체는 재작성으로
덮어써진다** — 반쪽 PIT. 따라서 재무는 절대 FMP 를 쓰지 않고, Sharadar 에 없는
두 가지만 맡긴다: 공매도 잔고(SHORT_INT_CHG), 애널리스트 추정치(PEG_FWD).
추정치는 수집 시작일 이후만 PIT 성립 (`04-data-contract.md` §2.5).

### Norgate — 불필요 판정 (2026-08-11)

Sharadar 유료 플랜이 폐지 종목을 포함한다고 벤더가 직접 확인했으므로
(`04-data-contract.md` §4), Norgate 를 살 이유였던 생존편향 해소가
Sharadar 안에서 끝난다. 실제 가격도 초판 기록(~$30-40)보다 높다 —
폐지 종목과 과거 지수 구성종목은 **Platinum $630/년(≈$52.5/월)** 부터다
(Silver $270 · Gold $360 은 현재 상장 종목만).

아래는 그럼에도 남는 가치의 기록이다. 가격 전용이지만 두 가지가 독보적:
생존편향 제거 품질의 업계 평판, 그리고
**과거 시점의 지수 구성종목** (S&P500 당시 멤버십). 후자는 우리가 아직 안 쓰지만,
"당시 S&P500 편입 종목만" 같은 유니버스를 원하게 되면 Sharadar 의
SP500 constituents 테이블로 먼저 시도하고, 품질 이슈 시 Norgate 를 추가한다.
또한 Sharadar SEP 수정주가의 **독립 교차검증 소스**로 가치가 있다
(kr-quant 에서 무검증 가격 데이터가 만든 사고의 재발 방지).

## 최종 구성과 비용

| 단계 | 구독 | 월 비용 | 잠금 해제되는 것 |
|---|---|---|---|
| **1단계 (지금)** | Sharadar Bundle | **$29** | 팩터 136개 중 129개 (SF1+SEP+DAILY+SF2+SF3) |
| 2단계 (선택) | + FMP Starter | +$15 = $44 | PEG_FWD, SHORT_INT_CHG, INST_SHORT_COMBO 등 7개 |
| ~~3단계~~ | ~~+ Norgate~~ | ~~+$52.5~~ | **불필요** — 폐지 종목이 Sharadar 유료에 포함됨 |

시스템은 `requires` 메타로 미구독 팩터를 자동 비활성화하므로 1단계만으로 완전 동작한다.

## 리스크와 재검토 트리거

- **Sharadar 직판 전환 리스크**: 직판($29)이 신설 채널이라 API 형태·안정성 미검증.
  구독 직후 `04-data-contract.md` §4 체크리스트 검증 → 실패 시 Nasdaq Data Link 경유로 폴백
  (어댑터는 NDL datatables 기준으로 이미 작성됨).
- **단일 벤더 의존**: 어댑터 계층이 벤더 중립이므로 교체 비용은 어댑터 1파일.
  치명적 품질 사고 시 EODHD(+자체 PIT 스냅샷 축적) 가 차선.
- **재검토 트리거**: Tradevo 가 분기 재무 + 상장폐지 + 가격을 추가하면 재평가.
  서버측 as_of 설계는 우리 스토어보다 우아하다.
